# 织境空间·场景界面扩展 v0.14.3 beta

织境空间的可选图形场景扩展，为部分原版地点增加可点击场景、家具摆放和角色图层。原版剧情选项保留，热点只调用当前页面已有的原版动作。

- 主 Mod：织境空间 v0.1.604 或更高版本，下载 https://github.com/Kanna-destiny/WovenRealm/releases/latest
- 图片接口：ModLoader DoL ImageLoaderHook 2.3.0 或更高版本
- 下载：https://github.com/Kanna-destiny/WovenRealmUI/releases
- 反馈：https://github.com/Kanna-destiny/WovenRealmUI/issues

## 安装

先加载主 Mod，再选择以下一个场景扩展包，三种包不可同时加载：

- `WovenRealmUI-v0.14.3-PC.zip`：桌面版。
- `WovenRealmUI-v0.14.3-Mobile.zip`：常规手机版，640px 资源。
- `WovenRealmUI-v0.14.3-Mobile-Compat.zip`：旧 WebView / 32 位 / 低内存设备，480px 资源。

进入“选项／设置 → 织境空间 → 场景界面”调整显示、热点、画质，以及家具素材备份与恢复。
