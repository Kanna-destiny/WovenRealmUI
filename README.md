# 织境空间·场景界面扩展

织境空间的可选图形场景 Mod，为部分原版地点增加可点击场景、家具摆放和角色图层，让地点与房间以图形界面呈现。

保留原版剧情选项，场景热点调用当前页面已有的原版动作。可在“选项／设置 → 织境空间 → 场景界面”调整场景显示、热点和画质，并管理家具素材的备份与恢复。

提供桌面版、手机版与手机兼容版，按设备选择一个包加载即可。需要先加载织境空间主 Mod v0.1.604 或更高版本，以及 ModLoader DoL ImageLoaderHook 2.3.0 或更高版本。
